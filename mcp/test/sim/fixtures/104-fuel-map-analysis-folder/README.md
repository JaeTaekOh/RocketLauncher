# FuelMate (com.sim.fuelmate) — Play store-readiness analysis folder

Reconstructed for Rocket Launcher from the signed Android App Bundle
`dist/fuelmate-1.3.0-vc13-release.aab` (versionName 1.3.0, versionCode 13). This folder is
not a buildable project.

- Login is optional. Android: Google only.
- In-app account deletion: Menu → 내 계정 → 내 계정 삭제 (acct.js runDelete).
- Web deletion page: https://simstudio.github.io/fuelmate/delete-account
- Privacy policy: https://simstudio.github.io/fuelmate/privacy
