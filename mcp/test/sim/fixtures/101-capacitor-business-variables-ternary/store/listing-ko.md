# SiteCrew: Google Play 스토어 등록 정보 (한국어)

기본 언어: **한국어 (ko-KR)** · 카테고리: 비즈니스 (Business) · 배포 국가: 대한민국

## 앱 이름 (8/30)
```
SiteCrew
```

## 간단한 설명
```
현장 직원용 업무 앱. 실측, 인수증, 작업보고서와 견적서를 휴대폰 하나로.
```

## 자세한 설명
```
SiteCrew는 회사 직원이 현장에서 쓰는 업무용 앱입니다.

※ 이 앱은 회사 직원 전용입니다. 관리자의 승인을 받아야 사용할 수 있습니다.

주요 기능
• 실측 기록: 현장별 치수를 단계별로 입력합니다.
• 인수증: 인계 내역을 작성하고 현장에서 서명을 받습니다.
• 작업보고서: 작업 전후 사진을 정리합니다.
• 견적서: 공급가와 부가세가 자동으로 계산됩니다.
```

개인정보처리방침: `https://simstudio.github.io/sitecrew/privacy`
