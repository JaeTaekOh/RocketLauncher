Rocket Launcher — Privacy Policy

Effective 2026-11-17

English · 한국어 · ภาษาไทย · 中文 · हिन्दी

English

Rocket Launcher reads and analyzes the app project you connect only inside your browser (web app) or on the computer running the MCP server. Files, analysis results and generated assets are not sent to or stored on any server, except the optional anonymized review-lesson record described below.

If you enter a public GitHub URL, public files are downloaded directly from GitHub. We never ask for tokens or passwords. Progress and your language choice are kept only on this device (browser localStorage, or ~/.rocketlauncher for the MCP server) so you can continue later, and are removed when you start a new app or clear that storage. Review results you paste are turned into short, generalized lessons kept only on this device (key rocketlauncher.lessons.v1 in the browser); they never include the store’s original message.

Shared review lessons. When a lessons API is configured, a real (non-demo) learned review result may send one small anonymized record to that API: the store (App Store or Google Play), the guideline / ITMS / Play policy codes found, a fixed advice id from Rocket Launcher’s own table, and whether it was a rejection or a later approval. It never sends the store’s message, your app’s name, bundle or package id, project id, file paths, e-mail addresses, names or any other text. The server is meant to keep only a running count per code and advice id (no rows per person). Rocket Launcher may also download the combined counts and show matching items as “From other reviews” reminders; their titles and advice come only from Rocket Launcher’s fixed table. The built-in demo never sends anything. If the lessons API is not configured or cannot be reached, everything keeps working on your device. For the MCP server, set ROCKETLAUNCHER_LESSONS_API to an empty value to keep lessons only on this computer; if the variable is omitted, the default URL in js/config.js is used.

Nothing is submitted to Google Play or the App Store by Rocket Launcher. You press the store’s submit button yourself.

한국어

Rocket Launcher는 연결한 앱 프로젝트 파일을 사용자의 브라우저 안(웹) 또는 MCP 서버가 실행 중인 컴퓨터에서만 읽고 분석합니다. 파일, 분석 결과, 만들어진 자료는 아래의 선택적 익명 심사 교훈 기록을 제외하고 어떤 서버로도 보내거나 저장하지 않습니다.

공개 GitHub URL을 입력하면 공개 파일을 GitHub에서 직접 가져옵니다. 토큰이나 비밀번호는 요청하지 않습니다. 진행 상태와 언어 선택은 이 기기에만 저장됩니다(브라우저 localStorage, 또는 MCP의 ~/.rocketlauncher). “새 앱 연결”을 하거나 그 저장소를 지우면 삭제됩니다. 붙여 넣은 심사 결과는 짧은 일반 교훈으로만 이 기기에 남고(rocketlauncher.lessons.v1), 스토어의 원문은 포함되지 않습니다.

심사 교훈 공유. 교훈 API가 설정된 경우에만, 데모가 아닌 실제 학습 결과를 그 API로 익명 기록 하나 보낼 수 있습니다(스토어, 가이드라인·ITMS·정책 코드, 고정 조언 ID, 반려/이후 승인 여부). 스토어 메시지, 앱 이름, ID, 경로, 이메일이나 다른 자유 텍스트는 보내지 않습니다. 데모는 보내지 않습니다. API가 없거나 연결되지 않으면 모든 기능은 이 기기에서만 동작합니다.

Rocket Launcher는 Google Play나 App Store에 직접 제출하지 않습니다. 제출 버튼은 사용자가 직접 누릅니다.

ภาษาไทย

Rocket Launcher อ่านและวิเคราะห์โปรเจกต์แอปที่คุณเชื่อมต่อ ภายในเบราว์เซอร์หรือบนคอมพิวเตอร์ที่รันเซิร์ฟเวอร์ MCP เท่านั้น ไฟล์ ผลการวิเคราะห์ และไฟล์ที่สร้างขึ้นจะไม่ถูกส่งหรือเก็บไว้บนเซิร์ฟเวอร์ ยกเว้นบันทึกบทเรียนแบบไม่ระบุตัวตนที่เลือกได้ด้านล่าง

หากใส่ URL GitHub สาธารณะ จะดาวน์โหลดไฟล์สาธารณะจาก GitHub โดยตรง ไม่ขอโทเค็นหรือรหัสผ่าน ความคืบหน้าเก็บไว้บนอุปกรณ์นี้เท่านั้น ผลการรีวิวที่วางจะถูกทำให้เป็นบทเรียนสั้น ๆ บนอุปกรณ์นี้ และไม่มีข้อความต้นฉบับจากสโตร์

การแชร์บทเรียนรีวิว. เมื่อตั้งค่า lessons API แล้ว ผลที่เรียนรู้จริง (ไม่ใช่เดโม) อาจส่งระเบียนนิรนามหนึ่งรายการไปยัง API นั้น (สโตร์, รหัสแนวทาง / ITMS / นโยบาย, รหัสคำแนะนำคงที่, และว่าเป็นการปฏิเสธหรือการอนุมัติภายหลัง) ไม่ส่งข้อความจากสโตร์ ชื่อแอป หรือข้อความอิสระ หากไม่ได้ตั้งค่า API หรือติดต่อไม่ได้ ทุกอย่างยังทำงานบนอุปกรณ์นี้

Rocket Launcher ไม่ได้ส่งแอปไปยัง Google Play หรือ App Store ให้คุณ คุณกดปุ่มส่งเอง

中文

Rocket Launcher 仅在你的浏览器内（网页版）或运行 MCP 服务器的计算机上读取并分析你连接的应用项目。除下文所述的可选匿名审核经验记录外，文件、分析结果和生成的材料不会发送到或存储在任何服务器上。

如果你输入公开的 GitHub 网址，将直接从 GitHub 下载公开文件。我们不会索要令牌或密码。进度仅保存在此设备上。你粘贴的审核结果会变成简短的概括性经验，保存在此设备上，绝不包含商店原文。

共享审核经验。 在配置了 lessons API 时，真实（非演示）学到的结果可能会向该 API 发送一条匿名记录：商店、准则 / ITMS / 政策代码、固定建议 ID，以及是拒绝还是之后的通过。绝不发送商店消息、应用名称、各类 ID 或其他自由文本。演示不会发送。若未配置 API 或无法连接，所有功能仍只在此设备上工作。

Rocket Launcher 不会向 Google Play 或 App Store 提交任何内容。提交按钮由你本人点击。

联系：GitHub issues

हिन्दी

Rocket Launcher आपके जुड़े ऐप प्रोजेक्ट को केवल आपके ब्राउज़र में (वेब ऐप) या MCP सर्वर चलाने वाले कंप्यूटर पर पढ़ता और विश्लेषण करता है। नीचे बताए वैकल्पिक गुमनाम समीक्षा-सबक रिकॉर्ड के अलावा फ़ाइलें, विश्लेषण और बनाई गई सामग्री किसी सर्वर पर नहीं भेजी या रखी जातीं।

यदि आप सार्वजनिक GitHub URL देते हैं, तो सार्वजनिक फ़ाइलें सीधे GitHub से आती हैं। हम टोकन या पासवर्ड नहीं माँगते। प्रगति केवल इस डिवाइस पर रहती है। आपके चिपकाए समीक्षा परिणाम छोटे सामान्य सबक बनकर इसी डिवाइस पर रहते हैं; स्टोर का मूल संदेश शामिल नहीं होता।

साझा समीक्षा सबक。 जब lessons API सेट हो, तो असली (डेमो नहीं) सीखे गए परिणाम उस API को एक छोटा गुमनाम रिकॉर्ड भेज सकते हैं: स्टोर, गाइडलाइन / ITMS / नीति कोड, तय सलाह ID, और अस्वीकृति या बाद की मंज़ूरी। स्टोर संदेश, ऐप का नाम, ID या अन्य मुक्त पाठ कभी नहीं भेजा जाता। डेमो कुछ नहीं भेजता। यदि API सेट नहीं है या पहुँच से बाहर है, तो सब कुछ इसी डिवाइस पर चलता रहता है।

Rocket Launcher Google Play या App Store पर कुछ सबमिट नहीं करता। सबमिट बटन आप खुद दबाते हैं।
