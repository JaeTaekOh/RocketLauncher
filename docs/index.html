Two ways to use it

Use the connect instructions on this page to add the MCP server to Grok Bot, Claude, Cursor, or Gemini CLI. Or open the web version in your browser — no install.

How to connect

The usual install is the npm package rocket-launcher-mcp. You need Node.js 20 or later. Prefer not to install anything? Open the web version.

$ npx -y rocket-launcher-mcp

Use that command in every config below.

Ask in a chat Easiest

Add an MCP server. Name Rocket Launcher, command npx, arguments -y rocket-launcher-mcp

Or add it yourself

  1. Connect apps→Add a custom connector
  2. Type
    Command
    Command
    npx
    Arguments
    -y rocket-launcher-mcp

Then

Tell the Bot “Help me launch my app with Rocket Launcher” and give it a public GitHub URL — or try the sample.

Claude Code Terminal

$ claude mcp add rocket-launcher -- npx -y rocket-launcher-mcp

Claude Desktop Mac · Windows

  1. Settings→Developer→Edit Config, then add this to claude_desktop_config.json: 
    {
  "mcpServers": {
    "rocket-launcher": {
      "command": "npx",
      "args": ["-y", "rocket-launcher-mcp"]
    }
  }
}
  2. Fully quit Claude and open it again.

mcp.json

  1. Add this to .cursor/mcp.json in your project, or to ~/.cursor/mcp.json for all projects: 
    {
  "mcpServers": {
    "rocket-launcher": {
      "command": "npx",
      "args": ["-y", "rocket-launcher-mcp"]
    }
  }
}
  2. Approve the server the first time Cursor asks.

settings.json

  1. Add this to ~/.gemini/settings.json (all projects) or .gemini/settings.json in one project: 
    {
  "mcpServers": {
    "rocket-launcher": {
      "command": "npx",
      "args": ["-y", "rocket-launcher-mcp"]
    }
  }
}
  2. Restart Gemini CLI and run /mcp to see the tools.

From a clone Alternative

If you prefer a local checkout, clone the repository, run npm install in mcp/, and use command node with the path to mcp/server.mjs.

$ git clone https://github.com/JaeTaekOh/RocketLauncher.git
$ cd RocketLauncher/mcp
$ npm install
After that, just talk to your AI. You only pick and approve. You press Submit yourself in Play Console or App Store Connect. Prefer not to install anything? Use the web version.

Twenty-two tools

Connect and decide

rocketlauncher_connect_app
Connect an app once (public GitHub URL, folder, ZIP, or the sample) and analyze it.
rocketlauncher_get_report
Show launch readiness and issues that can block review.
rocketlauncher_get_decisions
List choices with ready-made options and a recommendation.
rocketlauncher_decide
Record what you actually picked or approved.
rocketlauncher_status
Show the current step, the next action, and lessons learned on this computer.

Check before you submit

rocketlauncher_check_requirements
Check current store technical requirements and deadlines, with official sources.
rocketlauncher_privacy_check
Cross-check privacy labels, permission texts, and the policy, and draft what is missing.
rocketlauncher_play_policy_audit
A quick Google Play policy scan with Play Policy Insights.
rocketlauncher_account_deletion_check
Check in-app and web account-deletion paths when the app has sign-up.
rocketlauncher_report_correction
Report that a check was wrong. It is overridden for this app, readiness is recalculated, and an anonymized record can be shared.
rocketlauncher_version_sync
Check version and build numbers across platforms, including force-update safety.
rocketlauncher_country_check
Korea, EU, and Thailand rules that apply to the app. Summaries, not legal advice.
rocketlauncher_closed_test
Track Google Play’s 12 testers × 14 days closed-test rule.
rocketlauncher_reviewer_notes
Draft notes for store reviewers, with placeholders only — never real passwords.

Make store materials

rocketlauncher_preview_graphics
Show icon, feature-graphic, and screenshot options so you can pick.
rocketlauncher_generate_store_materials
Build the full launch kit: listings, privacy pages, form answers, graphics, and a ZIP.

Submit — you press the button

rocketlauncher_submission_guide
Walk through each store console, with the value for every field. The last step stays locked until you approve.
rocketlauncher_approve_submission
Record your approval. This does not submit anything.

After review

rocketlauncher_report_review
Record submitted, rejected, resubmitted, or approved. Returns a fix plan and a reply draft when needed.
rocketlauncher_forget_lesson
Remove one review lesson learned on this computer, only when you ask.

Move or remove an app

rocketlauncher_move_app_plan
Compare transferring an app with registering it again. AdMob is optional.
rocketlauncher_remove_app_guide
How to unpublish or delete an app on each store. Guide only; nothing is removed.
